קליטת מקורות נתונים והפעלת תהליכים מבוקרים באמצעות GitHub Actions.

● סביבת פיתוח
מצב נוכחי: אימון מתמשך וייצוא GGUF

אפשר לבדוק מקורות ולהפעיל אימון נוסף על checkpoint קודם. כל ריצה ממשיכה את המשקולות ואת מצב האופטימייזר ושומרת גרסה חדשה ב־Google Drive. לפני האימון הראשון יש להגדיר את הרשאות Drive ואת סודות המאגר לפי מדריך האימון.

01 / DATA SOURCE

01

מאגר ציבורי ב־GitHub או עמוד HTTPS ציבורי.

02 / CONNECTION

חיבור ל־GitHub

02

כדי להפעיל Workflow מתוך הדף, נדרש Fine-grained Personal Access Token עם הרשאות מתאימות למאגר IvritLM.

האסימון נשמר בזיכרון הדף בלבד. הוא אינו נשמר בדפדפן או במאגר. ניתן לנקות אותו או לסגור את הלשונית.

03 / MODEL TRAINING

הפעלת אימון מתמשך

02

הקובץ חייב להיות קובץ TXT בקידוד UTF-8 שכבר הועלה למאגר. המאגר ציבורי, ולכן תוכנו יהיה גלוי לציבור.

האימון ימשיך מה־checkpoint האחרון ב־Drive. בסיום תישמר גרסת checkpoint חדשה וייוצר קובץ GGUF. נדרשים סודות Google Drive המפורטים במדריך.
