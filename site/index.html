ניהול אימונים

בדיקת מקורות נתונים והפעלת אימונים מבוקרים באמצעות GitHub Actions.

● סביבת פיתוח
מצב נוכחי: אימון מתמשך וייצוא GGUF

אפשר להמשיך אימון קודם ולשמור תוצרים בתיקיית גרסת המודול המתאימה ב־Google Drive. בדיקת מקור יוצרת דוח מקור בלבד; היא עדיין אינה מוסיפה את תוכן המקור לקורפוס האימון. לפני אימון יש להגדיר את חיבור Drive ואת סודות המאגר לפי המדריך.

QUICK START / מדריך מהיר

מתחילים בחמש פעולות

מדריך
  1. מחברים את Google Drive פעם אחת: מריצים python scripts/google_drive_auth.py ובוחרים בחלון את קובץ ה-OAuth מסוג Desktop app.
  2. מגדירים ארבעה GitHub Secrets: מעתיקים את DRIVE_CLIENT_ID, DRIVE_CLIENT_SECRET, DRIVE_REFRESH_TOKEN ו-DRIVE_FOLDER_ID למסך Secrets של המאגר.
  3. יוצרים GitHub Token: הרשאת Actions Read and write למאגר IvritLM בלבד, ומדביקים אותו בשדה GitHub token.
  4. מכינים קורפוס: מעלים למאגר קובץ TXT בקידוד UTF-8 שיש הרשאה להשתמש בו לאימון.
  5. מפעילים אימון: מזינים את נתיב הקובץ, צעדים ו-Batch size ולוחצים על הפעלת אימון והפקת GGUF.
