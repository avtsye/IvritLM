ניהול אימונים

הוספת טקסטים וקישורים, בניית קורפוס עברי, אימון מתמשך וניהול תוצרי המודל — במקום אחד.

● סביבת פיתוח
סביבת עבודה אחידה: נתונים ← קורפוס ← אימון ← מודל

אפשר להזין טקסט ישירות, להעלות קובץ טקסט או לסרוק אתר ציבורי. החומר עובר ניקוי ובדיקת עברית, נשמר כקורפוס ב־Google Drive ומשמש לאימון המודל. כל התהליך והיסטוריית הריצות מרוכזים בדף זה.

QUICK START / מדריך מהיר

מתחילים בארבע פעולות

מדריך
  1. מחברים את Google Drive פעם אחת: מריצים python scripts/google_drive_auth.py ובוחרים בחלון את קובץ ה-OAuth מסוג Desktop app.
  2. מגדירים ארבעה GitHub Secrets: מעתיקים את DRIVE_CLIENT_ID, DRIVE_CLIENT_SECRET, DRIVE_REFRESH_TOKEN ו-DRIVE_FOLDER_ID למסך Secrets של המאגר.
  3. יוצרים GitHub Token: הרשאת Actions Read and write למאגר IvritLM בלבד, ומדביקים אותו בשדה GitHub token.
  4. מוסיפים חומר: מדביקים טקסט, בוחרים קובץ TXT או מזינים קישור לאתר ציבורי.
  5. מאמנים ומייצאים: בוחרים צעדי אימון ו־Batch size ומפעילים אימון והפקת GGUF.

נתקעת? אם קיבלת שגיאה בבחירת קובץ Google, אל תבחר token.json. צריך את קובץ ה-OAuth שהורדת מ-Google Cloud ושמו בדרך כלל מתחיל ב-client_secret_.

01 / DATA SOURCE

מקור נתונים חדש

01

מאגר ציבורי ב־GitHub או אתר HTTPS ציבורי. באתר: עד 500 עמודים ובעומק 5, תוך כיבוד robots.txt, מפת האתר ומגבלות זמן ונפח. הקורפוס יישמר כמועמד לאימון; יש לבדוק את הזכויות ואת התוכן לפני הפעלת אימון.

02 / CONNECTION

חיבור ל־GitHub

02

כדי להפעיל Workflow מתוך הדף, נדרש Fine-grained Personal Access Token עם הרשאות מתאימות למאגר IvritLM.

האסימון נשמר בזיכרון הדף בלבד. הוא אינו נשמר בדפדפן או במאגר. ניתן לנקות אותו או לסגור את הלשונית.

  • גישה למאגר IvritLM בלבד

חיבור Google Drive

החיבור מתבצע פעם אחת מהמחשב שלך באמצעות Google OAuth. לאחר מכן מוסיפים ארבעה GitHub Actions Secrets; דף הניהול אינו קורא או מציג את פרטי ההתחברות.

02 / ADD TRAINING TEXT

הוספת טקסט ישירות למאגר

טקסט / TXT

אפשר להדביק טקסט או לטעון קובץ TXT. בשלב זה מגבלת ההזנה הישירה היא 40,000 תווים לריצה. הטקסט יישלח ל־GitHub Actions, יעבור בדיקת עברית ויישמר ב־Google Drive כקורפוס חדש.

03 / MODEL TRAINING

הפעלת אימון מתמשך

02

אפשר להשאיר ריק כדי להשתמש בקורפוס האחרון שנוצר מתהליך קליטת המקורות ב-Drive. לחלופין, אפשר לציין נתיב יחסי לקובץ TXT שכבר נמצא במאגר הציבורי.

האימון ימשיך מה־checkpoint האחרון ב־Drive. בסיום תישמר גרסת checkpoint חדשה וייוצר קובץ GGUF. נדרשים סודות Google Drive המפורטים במדריך.

04 / CONVERSATION TRAINING

אימון יכולת שיחה

JSONL

כל שורה היא אובייקט JSON עם מערך messages. התפקידים המותרים: system, user, assistant; השיחה חייבת להסתיים בתשובת assistant. מומלץ להוסיף מאות ואלפי דוגמאות איכותיות ומגוונות. הנתונים משמשים לאימון נוסף על גבי checkpoint קיים.

נדרש אימון בסיסי קודם. בסיום נשמר checkpoint מעודכן ונוצר GGUF חדש ב־Google Drive.
